Recording your travels

A web app can't track you in the background on iPhone, so let Google Maps record and then import its file here.

  1. Install Google Maps and sign in.
  2. iPhone Settings → Privacy → Location Services → Google Maps: Always and Precise Location ON.
  3. In Google Maps tap your profile picture → Your Timeline and turn Timeline on. It records even with no mobile data.
  4. When you want to update the map: Google Maps Settings → Personal content → Export Timeline data. Save the file to Files.
  5. Here, tap Import location file and pick it. You can re-import the same file again later; duplicates are skipped.

More detail (optional): the free app Open GPX Tracker records every few seconds while it's running. Export a GPX and import it here too.

Your location never leaves this device. To see the map on another device, use Save backup file here and Load backup file there.

Erase every imported point from this device? Save a backup first if you want to keep it.
